Privacy

What the instance stores

Account data, profiles, follow and block relationships, public posts, likes, Seen history and reports are stored on the server. Private-message records contain only sender, recipient, ciphertext, IV, protocol version and date. The application intentionally sends no private-message plaintext to the server.

Metadata—including who communicated with whom, when, unread counts and read cursors—remains visible to the instance. The server also serves the JavaScript, so a malicious or compromised server could alter future client code. Browser storage holds your non-extractable private key.

Irrecoverable local keys

Clearing site data, changing browser profile or losing the device destroys the private key unless the browser itself preserves that storage. Old messages can then become permanently unreadable. There is no key escrow or recovery service.
