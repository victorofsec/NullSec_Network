Security

A functional privacy-focused prototype, not an audited messenger

NullSec Network uses ECDH P-256, HKDF-SHA-256 and AES-256-GCM through the Web Crypto API. Private keys are non-extractable and stored locally in IndexedDB. Public-key fingerprints help contacts compare keys, and the client warns when a saved contact key changes.

The project has not received a professional security audit and does not claim equivalence to Signal. It lacks multi-device key synchronization, forward secrecy, post-compromise security and robust identity verification. The server supplies the cryptographic JavaScript and observes metadata.

Do not use this prototype as the sole channel for sources, journalists, whistleblowers or extremely confidential information. Use a professionally audited, mature tool and an appropriate operational-security process for that risk level.

See the repository threat model and cryptography documentation before relying on it. Report vulnerabilities privately using the process in SECURITY.md.
